# Google Cybersecurity Certificate - Course 2  (Manage Security Risks)
## Botium Toys: Internal IT Audit & Risk Assessment (NIST CSF Project)

This project simulates an **internal cybersecurity audit** for a fictional company, **Botium Toys**, as part of the Google Cybersecurity Professional Certificate (Course 2: "Foundations of Cybersecurity").

The goal is to assess the current cybersecurity posture using the **NIST Cybersecurity Framework (NIST CSF)**, identify key vulnerabilities, and provide actionable recommendations.

---

### 📋 Project Objectives
- Perform a mock **internal IT security audit**
- Use the **NIST CSF framework** to evaluate risk and compliance
- Review and align with major compliance regulations:
  - PCI DSS
  - GDPR
  - SOC 1 & SOC 2
- Identify gaps and vulnerabilities in Botium Toys' infrastructure
- Present findings and remediation steps

---

### 🧠 Skills Demonstrated
- Cybersecurity auditing  
- Risk assessment  
- Policy and compliance review  
- Report writing and documentation  
- NIST CSF application in a business context
